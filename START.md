# So startest du

1. Ordner entpacken, z. B. nach `C:\dev\monchi`.
2. Terminal in dem Ordner öffnen, `git init`, dann `claude` starten.
3. Ersten Prompt eingeben:

   > Lies CLAUDE.md und alles in docs/. Dann Phase 0 aus docs/PLAN.md.

4. Danach Phase für Phase. Die Prompts stehen in docs/PLAN.md.
5. Nach jeder Phase im Spiel testen und Claude Code das Log (`%LOCALAPPDATA%\Monchi\logs\latest.log`) oder Screenshots geben.

Für GitHub erst ein privates Repo anlegen und erst ab Phase 7 öffentlich machen.
Den Namen "Monchi" vorher ändern, falls du einen anderen willst: Claude Code sagen "benenne das Projekt überall in <Name> um".
